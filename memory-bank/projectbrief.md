# Project Brief

Piano Tutor: a browser app to load a MIDI file, pick a part (track) to learn,
and practice it with a lit-up keyboard and a DAW-style piano-roll view.

Full scope, architecture, core decisions, and the milestone checklist live in
[PLAN.md](../PLAN.md) — that file is the source of truth for project scope.
This file exists only as a pointer into it; do not duplicate its content
here. See [progress.md](progress.md) for the current milestone status summary
and [systemPatterns.md](systemPatterns.md) / [techContext.md](techContext.md)
for architecture and stack details distilled from it.
